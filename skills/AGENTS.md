# Skills

Capabilities a user invokes by name for their output. `wiser/standards/primitives.md` owns type, invocation and frontmatter. The directory is flat and the index is grouped by category. The Owner column projects the declarations in the typed files. Draft Motion holds the document registers and the court and counsel checklists. The legal root’s Handoff label goes in the handoff message for each person-facing assessment, packet and draft, never inside a document.

## Deadline routing

Standalone deadline questions, including “What is due?” and “What is overdue?”, enter [Litigation Counsel’s preflight](../experts/Litigation%20Counsel/EXPERT.md#what-matter-and-deadline-govern), which runs Maintain Matter File’s [Deadline review](Maintain%20Matter%20File/SKILL.md#deadline-review-read-only), applies its working-period filter and reports a missing forum declaration before giving the answer. On any matter request, give its alert first under Litigation Counsel’s entry preflight, including when resuming work.

## Forum procedure

When the preflight forum finding names a forum pack file, read it after the matter's own records as a source for that forum's procedure. Give each pack statement's source, date read and state (`Verified` or `[verify]`) wherever it is used. Before using a stale statement, say `confirm: last read <date>` as given for that file and statement. For each rule used from the person's own pack, say that it came from the person's own pack and give its source and date read. A skill comparing candidate courts before a forum is declared reads each candidate's forum file through `lookup` and applies the same handling of source, state and age.

## Evidence labels

In working records, `[verify]` means `Unverified: requires confirmation`. State that label where the claim or figure appears and preserve it when carrying the claim forward. Use the other labels as applicable under `wiser/standards/conventions.md` Evidence Labels.

## Returning the work

Before returning any draft or strategic answer, ask “Is this our best thinking? What would a careful opponent attack?” State any weakness the check identifies and the hold it requires, if any. Change the draft in response to this check only when the person asks for that change. For a filing draft, end the handoff message with “After you file this, tell me so I can update the case record.”

For a result a skill will deliver to the person, apply [Owner review](../experts/AGENTS.md#owner-review) to the result type. Apply the legal root’s Handoff label and any release checks to the exact result.

# Skills

Capabilities a user invokes by name for their output. `wiser/standards/primitives.md` owns type, invocation and frontmatter. The directory is flat and the index is grouped by category. The Owner column projects the declarations in the typed files.

### Litigation phase

| Skill | Description | Owner |
|---|---|---|
| `Case Audit/SKILL.md` | A full case audit with documented coverage of claims, facts, arguments, evidence, opposition, trajectory, and follow-up | Litigation Counsel |
| `Discovery/SKILL.md` | A prioritized discovery plan, request or response draft, or dispute packet tied to the matter record | Litigation Counsel |
| `Motions Practice/SKILL.md` | A motion or opposition preparation packet with conferral, briefing deadlines, local requirements, and a pre-filing verdict | Litigation Counsel |
| `Pleadings/SKILL.md` | A matter-specific complaint, answer, or amendment drafting packet with a service and pre-filing checklist | Litigation Counsel |
| `Settlement Negotiation/SKILL.md` | A settlement preparation packet with sourced scenario assumptions, negotiation options, and a terms and dismissal review | Litigation Counsel |
| `Trial Preparation/SKILL.md` | A trial readiness packet with the schedule, binder map, witness and exhibit preparation, and preservation checks | Litigation Counsel |
| `Venue Selection/SKILL.md` | A sourced court and venue comparison with jurisdiction, threshold, timing, and procedural risk checks in the matter file | Litigation Counsel |

### Procedure

| Skill | Description | Owner |
|---|---|---|
| `Chronology/SKILL.md` | Build a sourced litigation timeline that connects events to pleaded issues and reconciles filing dates with tracked deadlines | Litigation Counsel |
| `Claim Chart/SKILL.md` | Map the verified elements of a claim or defense to sourced facts and evidence and show support gaps for the current litigation stage | Litigation Counsel |
| `Draft Motion/SKILL.md` | Draft a motion body and a sourced caption packet that clear citation and factual checks before court filing production | Litigation Counsel |
| `Maintain Matter File/SKILL.md` | Check matter deadlines first and keep events, source references, arguments, discovery needs and indexes in sync with the record | Litigation Counsel |
| `Open a Matter/SKILL.md` | Set up a matter's project record and prepare a new Colorado district civil case packet through filing, service and deadline seeding | Litigation Counsel |
| `Produce Court Filing/SKILL.md` | Compose, render and validate a court filing from sourced inputs, then deliver the filing artifact for human preview and approval | Litigation Counsel |
| `Take Over a Matter/SKILL.md` | Map an existing case folder into the matter contract and verify an approved copy-based adoption against the original inventory | Litigation Counsel |
| `Verify Citations/SKILL.md` | Check every legal citation and the proposition it supports, then return a citation report and an annotated draft with any filing holds | Litigation Counsel |

# Connectors

Authenticated access to outside platforms; `wiser/standards/primitives.md` owns the type's definition, invocation rules, and frontmatter. The directory is flat, and the index below is grouped by category.

This plugin ships no gateway. A connector that lands here loads through the base gateway's repeated `--connectors` flag, per `wiser/gateway/SETUP.md`.

This index is empty. This family holds no primitive yet.

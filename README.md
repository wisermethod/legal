# Legal

A WISER plugin for legal work.

Not yet built. This repository reserves the name and holds the place; there is nothing to install.

## Status

Empty and unscoped as of 2026-09-14. Reserved 2026-08-26 as Pro Se Lawyer; renamed 2026-09-14. The plugin has no skills, experts, tools, or connectors yet, and no build has been planned.

## What it will be

A harness-agnostic capability plugin in the same shape as the other WISER plugins: an authoring tree of skills, experts, tools, and connectors, projected into an installable bundle, governed by a runtime charter. It will run wherever a plugin of that shape can be loaded.

It loads alongside the Wiser plugin and assumes Wiser is installed. Wiser stays the writing, playbook, and connecting layer; this plugin is the legal bench on top of it.

Nothing it produces is legal advice, and nothing in it substitutes for a lawyer.

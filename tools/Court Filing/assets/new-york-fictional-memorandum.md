## Preliminary Statement

Defendant Fictional Widgets, Inc. asks the Court to set a date for the parties to file a joint proposed exhibit list for a future conference. The proposed list would identify the materials the parties expect to discuss. The parties could use the same index during the conference and refer to each item by its listed number.

## Background

The fictional dispute concerns a contract for sample widget packaging. The parties have drafted separate lists of materials for the conference. The draft lists include a purchase order, a sample shipment log, and correspondence about the packaging sample. Some items appear on both lists under different descriptions.

In the example affidavit, Robin Sample describes the defendant’s draft, which groups records by subject. The plaintiff’s draft lists records in the order they were created. A joint list would give each record one reference number and preserve both descriptions where they differ.

Each party could identify the items it expects to discuss and mark any entries shared by both sides. For records with several versions, the list could add a short version identifier. A single entry could also identify multiple pages of the same record, so the parties can locate each page during the discussion.

## Proposed Schedule

The requested order would set one date for filing the list. Before that date, the parties would have time to compare their draft entries and prepare a single document. The list could contain a number for each entry, a brief description, and the name of the party that included it. Both parties could review the combined draft before it is filed.

A common index would give the Court and the parties a reference for the conference. If an item needs clarification, the participants could identify it by its entry number and discuss the description in that setting. Each party could identify additional entries for discussion if the Court requests them at the conference.

## Conclusion

Defendant respectfully requests an order setting a date for the parties to file a joint proposed exhibit list.
